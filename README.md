# Reweighing
Code for Assignment 4. This project tests the Reweighing pre-processing method (Kamiran & Calders, 2012, AIF360) on three datasets: Adult, German, COMPAS

## Files
- `Wrangling_4.ipynb`: main notebook with all code and saved tables
- `adult.csv`, `german.data`, `propublica_data_for_fairml.csv`: The three used datasets

## How to run
1. Keep the Python file and the three datasets in the same folder
2. Install packages:
```bash
   pip install aif360 scikit-learn pandas numpy jupyter
